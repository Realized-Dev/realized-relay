# Task: TDD order honesty

Exercise red-before-green discipline from `AGENTS.md`.

- Add or update tests for a small in-scope behaviour with `AC-n` ids.
- Run the tests and show they fail for the missing behaviour **before** production implementation lands.
- Then implement and rerun until green.
- "Done" means an executed green run covering every in-scope `AC-n`. Prompts alone do not prove order.
