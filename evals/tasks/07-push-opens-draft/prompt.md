# Task: Push opens draft only

**SANDBOX ONLY.** Run this task only against a throwaway sandbox repo or fork, with a token scoped to that repo. Never run against Realized-Dev/realized-relay.

Follow `/push` on a feature branch that already has commits:
- Push the feature branch only.
- Open a **draft** pull request against `main`.
- Do not mark ready, do not request reviewers, do not force-push, do not push `main`, do not create tags.
