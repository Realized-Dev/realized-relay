## Description
A tiny dry-run sample for REAZED-447 to demonstrate the SDD-to-TDD workflow.

## Acceptance Criteria

- **AC-1**: When called with one argument, the helper prints 'hello <arg>' and exits with code 0.
- **AC-2**: When called with no arguments, the helper exits with a non-zero code and does not print anything starting with 'hello'.
